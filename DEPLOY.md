# Запуск бота на сервере — пошагово

Инструкция для тех, кто никогда не работал с сервером. Просто выполняй команды
по порядку. Всё, что нужно копировать, — в блоках кода.

---

## Что понадобится

- Заполненный файл `.env` (проверь у себя на компьютере: `python check_config.py`)
- Три картинки в папке `content/`: `announce.jpg`, `menu.jpg`, `payment_qr_vnd.jpg`
- 15 минут времени

---

## Шаг 1. Завести сервер (VPS)

1. Зарегистрируйся на **[hetzner.com](https://www.hetzner.com/cloud)** (дёшево, ~€4/мес).
   Альтернатива ближе к Вьетнаму — любой VPS в **Сингапуре**.
2. Создай сервер: **New Project → Add Server**
   - Локация: **Германия** или **Сингапур** (НЕ Вьетнам — там Telegram бывает капризным)
   - Образ: **Ubuntu 24.04**
   - Тип: самый дешёвый (например, CX22)
   - Способ входа: пароль придёт на почту, либо добавь SSH-ключ
3. Запиши **IP-адрес** сервера (вида `123.45.67.89`).

> 💡 Про Вьетнам: твой сервер общается с серверами Telegram, а не с телефонами
> гостей напрямую. Гости подключаются к Telegram сами. Так что где стоит сервер
> — на работу для аудитории во Вьетнаме не влияет. Время событий уже настроено
> по Вьетнаму (`TIMEZONE=Asia/Ho_Chi_Minh`).

---

## Шаг 2. Подключиться к серверу

На своём компьютере открой терминал и введи (подставь свой IP):

```bash
ssh root@123.45.67.89
```

Введи пароль (при вводе он не отображается — это нормально).

---

## Шаг 3. Скачать бота на сервер

```bash
cd /opt
git clone АДРЕС_РЕПОЗИТОРИЯ kindzadza-bot
cd kindzadza-bot
git checkout claude/bot-testing-validation-CZT2j
```

> `АДРЕС_РЕПОЗИТОРИЯ` — ссылка из GitHub (зелёная кнопка Code → HTTPS).

---

## Шаг 4. Создать `.env` на сервере

```bash
cp .env.example .env
nano .env
```

Откроется редактор — впиши свои значения. Сохранить: **Ctrl+O**, затем **Enter**.
Выйти: **Ctrl+X**.

> Можно вместо этого скопировать готовый `.env` с компьютера (см. Шаг 5).

---

## Шаг 5. Залить картинки (и при желании `.env`)

Открой **новый терминал на своём компьютере** (не на сервере), перейди в папку
проекта и выполни:

```bash
scp content/announce.jpg content/menu.jpg content/payment_qr_vnd.jpg \
    root@123.45.67.89:/opt/kindzadza-bot/content/
```

Если хочешь скопировать и `.env` с компьютера (чтобы не вписывать вручную):

```bash
scp .env root@123.45.67.89:/opt/kindzadza-bot/.env
```

---

## Шаг 6. Установить и запустить — ОДНА команда

Вернись в терминал, где ты на сервере, и выполни:

```bash
bash deploy.sh
```

Скрипт сам:
- установит всё необходимое,
- проверит твой `.env`,
- настроит автозапуск,
- запустит бота.

В конце увидишь `✅ Готово!`. Если будет `❌` — скрипт подскажет, что не так.

---

## Шаг 7. Проверить, что работает

Со своего телефона напиши боту `/start` — должно прийти приветствие с картинкой
анонса. 🎉

---

## Полезные команды (на сервере)

```bash
journalctl -u kindzadza-bot -f      # смотреть логи вживую (выход: Ctrl+C)
systemctl restart kindzadza-bot     # перезапустить бота
systemctl stop kindzadza-bot        # остановить
systemctl status kindzadza-bot      # текущий статус
```

---

## Как обновить бота позже (если поменялся код)

```bash
cd /opt/kindzadza-bot
git pull
bash deploy.sh
```

`deploy.sh` безопасно запускать сколько угодно раз — он обновит зависимости и
перезапустит бота.

---

## Если что-то пошло не так

1. Посмотри логи: `journalctl -u kindzadza-bot -n 50`
2. Проверь конфиг: `.venv/bin/python check_config.py`
3. Самые частые причины:
   - неверный `BOT_TOKEN` → бот не стартует
   - не заполнен `ADMIN_GROUP_ID` → не приходят оплаты на подтверждение
   - бот не добавлен в админ-группу → не видит сообщения оргов
